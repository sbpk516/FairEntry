1. Basic eligibility — shared by all versions

Want only size and price checks? Set dollar volume to 0 and choose Basic checks only. Zero disables the liquidity requirement, including for missing volume.

Prices below $1 and market caps below $300M are not in this data feed. Lower limits cannot be tested here.

2. Compare screening versions

Each count uses the basic settings above, before company search. Click a version to see its list. “Remove all 3” means removing P/B, P/S and P/FCF; other Deep Value checks remain.

3. Customize the selected version

Uncheck a rule to ignore it. Deep Value requires any one enabled valuation ratio, plus its enabled price-change and debt checks. If all three ratios are off, no cheapness check is applied. Missing gross margin or debt/equity is allowed, matching production; other missing required values fail.

P/B = price / book value. P/S = price / sales. P/FCF = price / free cash flow. Ratios are screening shortcuts, not proof that a company is undervalued. Disabling every check in a route lets all basically eligible listings pass that route.

Enter valid thresholds. The data starts at $300M and above $1; liquidity cannot be negative.
